## 🚀 Featured Build: VivahGo

- Built the complete product from scratch: frontend, backend, database design, auth, payments, and deployment.
- Shipped planner collaboration with roles (`owner`, `editor`, `viewer`), public wedding websites, RSVP workflows, vendor onboarding, subscriptions, careers, and admin operations.
- Supports both local Express development and Vercel-style serverless API deployment.
- Integrated cloud object storage for public and private document/media flows.

### VivahGo Stack Highlights

- **Frontend:** React 19, Vite, Tailwind CSS
- **Backend:** Express 5, Vercel Serverless Functions
- **Data:** MongoDB, Mongoose
- **Auth:** Google OAuth, JWT sessions
- **Payments:** Razorpay
- **Storage:** Cloudflare R2, Backblaze B2 (S3-compatible)
- **Quality:** Mocha, Supertest, c8, ESLint
- **Mobile:** Capacitor iOS wrapper
